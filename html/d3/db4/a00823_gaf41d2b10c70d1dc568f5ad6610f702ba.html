bool SystemEx.Threading.ILock.Wait ( TimeSpan span,
bool exitContext )

Temporarily releases the lock and suspends the current thread until a notification is received or the specified timeout expires. Upon completion, the lock is automatically reacquired. This method provides a generalized wait‑and‑reacquire pattern similar to Monitor.Wait(object, TimeSpan, bool).

Parameters
spanMaximum duration to wait for a notification.
exitContextIndicates whether the synchronization context should be exited before waiting.
Returns
true if the wait completed due to a notification; otherwise false.
