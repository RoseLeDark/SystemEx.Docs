Detailed Description

Provides a generic wrapper combining a CRC‑32 and a CRC‑64 hashing implementation. The generic parameters TC32 and TC64 specify the concrete CRC‑32 and CRC‑64 algorithm variants to use, allowing flexible configuration of polynomial families without modifying the pipeline.

Template Parameters
TC32A concrete CRC32 implementation used for 32‑bit hashing. Must provide a parameterless constructor.
TC64A concrete CRC64 implementation used for 64‑bit hashing. Must provide a parameterless constructor.
