Detailed Description

Represents the result of an AI model execution.

A ModelResult<T> contains:

  • The final model output (Result)
  • Metadata describing execution details (Metadata)
  • Optional error information (Error)
  • Optional raw backend output (Raw)
  • A timestamp indicating when the result was produced (Timestamp)
  • A success flag (Success)

This struct is immutable and safe to pass by value.
