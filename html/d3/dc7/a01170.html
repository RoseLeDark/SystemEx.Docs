Detailed Description

Defines a contract for collections that can automatically grow their internal storage when additional capacity is required.

Implementations use GrowSize to determine how much the underlying buffer should expand and AutoGrow to control whether growth occurs implicitly during insertion.

The Grow method performs the actual capacity increase and returns true if the operation succeeded.
