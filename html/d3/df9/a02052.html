bool Lock (int ms=-1)
 Attempts to acquire the lock using a millisecond timeout. A negative value indicates an immediate, non‑blocking attempt. Positive values are forwarded to Monitor.TryEnter(object, int, ref bool).
bool Lock (TimeSpan span)
 Attempts to enter the critical section by acquiring the internal lock. This overload accepts a TimeSpan timeout and uses Monitor.TryEnter(object, TimeSpan, ref bool) to determine whether the lock was successfully taken.
bool TryLock ()
 Attempts to acquire the lock using a TimeSpan timeout. This method is functionally identical to Lock(TimeSpan) but semantically expresses a non‑blocking intent.
void Unlock ()
 Releases the internal lock. Every successful call to Lock(TimeSpan) or Lock(int) must be paired with a corresponding call to Unlock to avoid deadlocks.
bool Wait (TimeSpan span, bool exitContext)
 Temporarily releases the lock and suspends the current thread until a pulse notification is received or the specified timeout expires. Upon completion, the lock is automatically reacquired. This method wraps Monitor.Wait(object, TimeSpan, bool).

Detailed Description

Provides a minimal wrapper around Monitor to offer lightweight mutual exclusion. LightLock is intended for short, low‑overhead critical sections where a full synchronization primitive would be unnecessary.
