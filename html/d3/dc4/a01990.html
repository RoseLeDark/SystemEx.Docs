Detailed Description

Defines an 8‑bit floating‑point format based on IFloat<TSelf, TBias>.

IFP8<TSelf> is intended for extremely compact numeric representations such as FP8 variants used in machine learning or embedded systems. The exact bit layout (sign, exponent, mantissa) is determined by the IFloat<TSelf, TBias> implementation.
