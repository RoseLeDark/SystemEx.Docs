Detailed Description

Internal BLAKE3 hasher implementation. This class manages the chaining values, chunk state, and compression stack required for incremental hashing.

Internal BLAKE3 flag definitions used during chunk and tree hashing.

Internal utility helpers for the BLAKE3 hashing subsystem.

Internal BLAKE3 constant definitions used by the hashing subsystem.

Internal scalar BLAKE3 compression implementation.

Internal state manager for a single BLAKE3 chunk.

This type is not intended for public use. It provides the internal logic behind the SystemEx BLAKE3 wrapper and exposes only the minimal API needed by higher‑level hashing components.

This class tracks the chaining value, chunk counter, block buffer, buffer length, and compression flags required during incremental hashing. It handles chunk filling, finalization, and resetting according to the BLAKE3 specification.

All members are internal and used only by the SystemEx.Hash.Black3 hashing subsystem.

This class provides the portable fallback version of the BLAKE3 compression function. It operates entirely on 32‑bit words and does not use SIMD instructions. All methods are internal and intended only for the SystemEx hashing subsystem.

This class provides fixed sizes and limits required by the portable compression implementation, including block length, key length, chunk size, output size, and maximum tree depth.

These values are part of the BLAKE3 specification and should not be modified. The type is internal and used only by the SystemEx hashing components.

This class provides constants, message schedules, bit operations, key loading, block loading, and chaining‑value storage helpers used by the portable scalar compression implementation.

All members are internal and intended only for use inside the SystemEx.Hash.Black3 module.

These flags control how each block or chunk is interpreted by the compression function, including start/end markers, parent node processing, keyed hashing, and key derivation modes.

This enum is internal and used only by the SystemEx.Hash.Black3 hashing subsystem.
