Detailed Description

Provides a scoped unlock mechanism for an existing ILock instance. Upon construction, the lock is immediately released. When the scope ends, Dispose reacquires the lock using the specified timeout.

ScopedUnlock<TLOCK> is useful for wait‑and‑resume patterns, producer/consumer scenarios, or any situation where a lock must be temporarily released while guaranteeing reacquisition.
