Detailed Description

Represents a model‑agnostic prompt container used by all IModelBackend implementations and embedded models.

An IModelPromp<T> encapsulates the raw prompt, contextual metadata, session information, backend parameters, and optional tags.
It provides a unified structure for passing input into any model pipeline, regardless of modality or backend type.

TThe underlying prompt type (e.g., text, tokens, bytes, AST, etc.).
