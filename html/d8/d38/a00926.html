Detailed Description

A specialized search provider implementing binary-search-based probing.

This provider assumes that the underlying TContainer is sorted according to the predicate or comparison logic used. It performs a midpoint probe to locate any matching element and then expands outward to collect all adjacent matches. This makes the provider efficient for clustered or repeated values in sorted sequences.

Important: This search provider is only valid for sorted containers. If the data is not sorted, use a linear search provider instead.

Behavior:

  • Find returns the number of matching elements by probing the midpoint and expanding left/right until non-matching elements are encountered.
  • Where returns all matching elements together with their indices.
  • Matching is determined solely by the provided predicate or ISimpleCompare<T> implementation.
