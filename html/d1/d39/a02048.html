Detailed Description

A one-shot countdown synchronization primitive. The latch starts in the locked state and releases all waiting threads once its internal counter reaches zero. After releasing, the latch remains permanently open.

Template Parameters
TThe lock type used to block threads until the latch opens. Must implement ILock.
