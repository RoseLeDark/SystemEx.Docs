bool SystemEx.Threading.ThreadEx.Commit ( ThreadInvokeMessage type,
Object message,
byte prio,
bool end = false )

Commits a message into the active invoke context, provided the commit window has not expired.

If the commit window is still open, the message is appended to the context queue with the specified priority.
When end is true, the invoke context is terminated after the message is committed.

If the commit window has already elapsed, the context is automatically closed by checkEndContext and no message is added.

Parameters
messageThe message payload consisting of a ThreadInvokeMessage identifier and an associated object.
prioThe priority value assigned to the message.
endIndicates whether the invoke context should be terminated after committing the message.
When true, the invoke-state bit is cleared, the commit window timer is stopped and reset, and the context mutex is released.
Returns
true if the message was successfully committed while the invoke context was still active;
false if the commit window had already expired and the context was automatically closed.
