Detailed Description

Provides deterministic binary serialization and deserialization for a type T using a schema TSchema .

Implementations must operate strictly on Cache and must not allocate temporary buffers other than the final output array.

TThe data type being serialized.
TSchemaThe schema describing the binary layout of T .
