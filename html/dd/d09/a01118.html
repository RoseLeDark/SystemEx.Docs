Detailed Description

Provides a Fibonacci‑based search strategy for containers implementing IContainer<T>.

Fibonacci search is an alternative to binary search that uses decreasing Fibonacci intervals to narrow the search space. It is particularly suited for sorted containers and scenarios where comparison operations are more expensive than index arithmetic.
