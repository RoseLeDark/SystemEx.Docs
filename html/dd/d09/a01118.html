Detailed Description

Represents a optional value container that stores a value only when HasValue is true. Unlike Nullable<T>, this type does not preserve null as a stored value; assigning null clears the optional state.

Template Parameters
TThe underlying value type. Can be either a reference type or a value type.

Compares this optional instance with another optional instance and returns a CompareResult describing their relative ordering.

Parameters
otherThe optional instance to compare against.
Returns
A CompareResult value indicating whether this instance is less than, equal to, or greater than the specified instance.

Comparison rules:

  • An empty optional (HasValue is false) is always considered greater than a non‑empty optional, ensuring that empty values sort last.
  • If both optionals are empty, they are considered equal.
  • If both contain values, the comparison is performed using Comparer<T>.Default and the result is cast directly to CompareResult.
