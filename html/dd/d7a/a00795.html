enum SystemEx.Threading.ThreadExState

Represents the lifecycle states used by ThreadEx and lightweight thread implementations. These states describe creation, startup, execution, pausing, and termination requests in a minimal and predictable manner.

Enumerator
Creating 

The thread object is being constructed and has not yet been started.

Waiting 

The thread has been scheduled to start (Start() was called), but its execution routine has not begun running yet.

Started 

The thread has begun executing its entry routine.

RequestAbort 

A cooperative request to abort the thread has been issued. The thread should terminate itself at the next safe point.

RequestKill 

A forced termination request has been issued. This indicates an immediate kill operation rather than a cooperative shutdown.

Pause 

The thread is paused and will resume only when explicitly signaled.

Suspend 

The thread is suspended and not allowed to continue until a resume operation occurs.

Stopped 

The thread has fully stopped and will not execute further instructions.

Running 

The thread is actively running and executing its assigned work.
