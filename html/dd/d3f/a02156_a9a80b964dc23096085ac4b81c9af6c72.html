SeedMixed SystemEx.Rand.SeedMixed.Mix< T > ( T other,
SeedMix type,
uint value = 2 )

Mixes the current seed with another seed using the specified mixing strategy. The operation is performed in a thread‑safe manner and may apply arithmetic, bitwise, shift, or rotation‑based transformations. When SeedMix.User is selected, the user‑defined mixing delegate OnUserMix is invoked instead.

Template Parameters
TThe seed type, constrained to ISeed.
Parameters
otherThe seed to mix with the current seed.
typeThe mixing strategy to apply.
valueAn optional parameter used by certain mix operations (e.g. shift and rotation amounts). Defaults to 2.
