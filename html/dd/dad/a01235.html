Detailed Description

Provides a high‑level wrapper around the Base Class Library (BCL) System.Random type. This implementation redirects all random‑number generation to the SystemEx random subsystem, allowing deterministic, engine‑agnostic, endian‑aware, and extended numeric random operations.

This class preserves the public API surface of System.Random while internally delegating all operations to RandUtils. The underlying engine is selected by Randx, which may use either Isaac32Engine (default) or MTwisterEngine depending on compilation flags or other.
