enum SystemEx.IO.RCUStreamState

Indicates the current operational state of an RCUStream<TStream>. Readers observe Current when no writer is active, and Update when a writer holds the exclusive lock.

Enumerator
Current 

No writer is active; read operations observe the current stable data.

Update 

A writer is active; readers may observe stale data while the update operation is in progress.
