Detailed Description

Provides an extensible search wrapper over a container using a configurable ISearchProvider<TContainer, T> strategy.

Purpose: The Search struct is designed for advanced and domain‑specific search algorithms that go beyond the simple linear scan implemented by Find<T, TContainer>. While Find offers a fixed, straightforward lookup, Search allows plugging in custom providers such as binary search, segmented search, pattern matching, or any specialized logic required by the application.

Fallback behavior: A LinearSearchProvider may be used as a fallback, but it is not the primary purpose of this type. Search exists to support complex, optimized, or domain‑specific search strategies.

Equality operators: The operators == and != are overloaded to provide concise existence checks:

if (search == value) { ... } // value exists
if (search != value) { ... } // value does not exist

These operators do not define structural equality. They only test whether the given value is present in the underlying container.

Equals(object): Always returns false. Search is a ref struct and cannot be compared to arbitrary boxed objects. Structural equality is intentionally not defined.
