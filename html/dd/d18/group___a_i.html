Detailed Description

Represents a generic AI model instance within the SystemEX framework.

Represents the result of an AI model execution.

Defines the data format returned by a backend during model execution.

This class acts as the high‑level controller for:

  • Model configuration (capabilities, environment, runtime settings)
  • Tool registration and management
  • Backend interaction (Begin, RunAsync, End)
  • Prompt execution and session handling

The model is generic over: T → The prompt/input type TTOOL → The runtime tool type used by the backend

A model does NOT execute AI logic itself. Instead, it delegates all execution to the backend (IModelBackend<T, TTOOL>).

This enum follows the AI_FORMAT_XXX naming convention and provides stable integer identifiers for all supported formats.

A ModelResult<T> contains:

  • The final model output (Result)
  • Metadata describing execution details (Metadata)
  • Optional error information (Error)
  • Optional raw backend output (Raw)
  • A timestamp indicating when the result was produced (Timestamp)
  • A success flag (Success)

This struct is immutable and safe to pass by value.

enum SystemEx.AI.ModelMeta : int

Defines strongly typed metadata keys for model execution.

Naming follows the AI_META_XXX convention, Values are grouped logically and designed to remain stable for long-term API usage.

These metadata keys describe backend information, model details, request/response properties, execution metrics, tool usage, and error diagnostics.
