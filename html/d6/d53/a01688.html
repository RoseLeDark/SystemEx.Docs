Detailed Description

Public BLAKE3 hasher implementation used by the SystemEx hashing subsystem.

Black3Hasher is a high‑level wrapper around the internal BLAKE3 chunk and tree‑hashing engine. It supports keyed hashing, endian‑aware output conversion, and integrates with the SystemEx attribute‑driven hashing model via HashAlgorithmAttribute.

Unlike simple one‑shot hash functions, this hasher drives the full BLAKE3 state machine: chunk accumulation, compression, chaining‑value propagation, and finalization. It produces stable 32‑bit and 64‑bit hash values suitable for identifiers, lightweight integrity checks, or general hashing tasks.
