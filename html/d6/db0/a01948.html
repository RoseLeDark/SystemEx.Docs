Detailed Description

Extends ISeed with a typed update mechanism. This generic interface allows seed implementations to accept external values that influence or mutate the internal seed state. The type parameter defines the kind of input used for updating the seed.

Template Parameters
TThe type of the value used to update the seed. Implementations may use this value to modify individual seed components, refresh time‑based values, apply mixing logic, or perform any custom mutation.
