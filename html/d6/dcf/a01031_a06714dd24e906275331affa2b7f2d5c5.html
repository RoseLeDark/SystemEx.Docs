long SystemEx.Algorithms.BinarySearcherProvider< T, TContainer >.Find ( ref TContainer container,
Func< Optional< T >, CompareResult > func )

Searches the container using a custom predicate callback. The callback receives each element and a boolean flag that can be used to indicate a match condition.

Parameters
containerThe container to search.
funcA predicate callback invoked for each element. The callback receives the element and a boolean indicating whether it matches the desired condition.
Returns
The index of the first element for which the callback indicates a match, or -1 if no element satisfies the predicate.
