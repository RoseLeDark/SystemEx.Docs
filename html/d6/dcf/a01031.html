Detailed Description

Provides binary serialization and deserialization capabilities for a type. Implementations define how an instance is encoded into a byte sequence and how it is reconstructed from raw binary data.

The interface supports endian‑aware serialization and allows writing the encoded representation into an existing buffer at a specified offset.

Template Parameters
TSelfThe implementing type that provides its own binary encoding and decoding logic.

void SystemEx.IByteSerializable< TSelf >.ToBytes ( ref byte[] destination,
long offset,
Endian endian )

Writes the binary representation of the current instance into an existing destination buffer at the specified offset .

The caller is responsible for ensuring that the buffer is large enough to hold the encoded data starting at the given offset. Bytes before the offset remain untouched and can contain arbitrary user data.

Parameters
destinationThe target buffer into which the encoded value will be written.
offsetThe position within destination where the encoded data will be written. For example, if offset = 100, bytes 0 through 99 remain unchanged, and the encoded value begins at index 100.
endianThe byte order used to encode the value.

Implemented in SystemEx.Numeric.Half16, and SystemEx.Numeric.Half16b.
