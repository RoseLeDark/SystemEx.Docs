Detailed Description

Provides a managed thread wrapper with event‑based control mechanisms. ThreadEx supports starting, stopping, pausing, resuming, joining, and sending custom events to the running thread.

The class uses EventGroup<TFastType> for thread state signaling and LightLock for synchronization. Several callback hooks allow custom behavior during setup, execution, pausing, cleanup, and termination.

ThreadEx is designed for deterministic thread control without relying on heavy synchronization primitives. All state transitions are represented as bit flags inside an EventGroup<Fast_Int>.

Reserved event bits:

  • 0 — Joinable
  • 1 — Started
  • 3 — Pause requested
  • 4 — Continue requested

Custom events may use bits ≥ 4.

bool SystemEx.Threading.ThreadEx.Start ( Object? userData,

Starts the thread and waits until the thread signals that it has begun execution or until the optional timeout expires.

Parameters
userDataArbitrary user data passed to all callback handlers.
timeoutMSMaximum time in milliseconds to wait for the thread to enter the running state. A value of -1 indicates an infinite wait.
Returns
