◆ Where()

Vector< Pair< long, Optional< T > > > SystemEx.Algorithms.ISearchProvider< T, TContainer >.Where ( ref TContainer container,
Func< Optional< T >, CompareResult > func )

Performs a full linear scan over the container and returns all elements that satisfy the given predicate together with their positions.

Unlike Find, which only returns the number of matches, Where provides detailed match information. Each result contains both the index of the element inside the container and the element itself. This is especially useful when T is a reference type and positional context is required.

Parameters
containerThe container to search.
funcPredicate used to test each element.
Returns
A Vector<T> containing all matching elements. Each pair stores:
  • The index of the element in the container
  • The element itself

Implemented in SystemEx.Algorithms.BinarySearcherProvider< T, TContainer >, SystemEx.Algorithms.FibonacciSearcherProvider< T, TContainer >, and SystemEx.Algorithms.LinearSearchProvider< T, TContainer >.
