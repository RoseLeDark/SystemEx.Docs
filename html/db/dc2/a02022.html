Detailed Description

Represents a signed 4‑bit integer stored inside a Fast_Byte.

The format uses 1 sign bit (bit 3) and 3 magnitude bits (bits 0–2), providing a value range from −8 to +7. All arithmetic operations are implemented through explicit bitwise logic using temporary bits inside the underlying Fast_Byte instance.
