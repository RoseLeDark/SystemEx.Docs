Detailed Description

Provides a thin wrapper around System.Threading.SpinLock to expose a busy‑wait mutual exclusion primitive through the ISpinlock<T> interface.

Spinlock is intended for extremely short critical sections where blocking or kernel transitions would introduce unnecessary overhead. The lock repeatedly attempts to acquire ownership using atomic operations and does not provide any wait/pulse semantics.
