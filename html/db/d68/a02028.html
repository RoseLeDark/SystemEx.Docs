Detailed Description

Extends ILock<T> with spin‑lock‑specific diagnostics and metadata. Implementations of ISpinlock<T> represent busy‑wait mutual exclusion primitives where threads repeatedly attempt to acquire the lock without yielding.

This interface exposes additional state information commonly associated with spin locks, such as whether the lock is currently held and whether the calling thread owns the lock.

Template Parameters
TThe underlying handle type used by the spin lock implementation. Typically System.Threading.SpinLock.
