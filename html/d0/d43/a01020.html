Triple SystemEx.Algorithms.ISimpleCompare< T >.Compare ( Optional< T > a,
Optional< T > b )

Compares two values and returns true if the comparison condition defined by the implementation holds; otherwise false.

The meaning of “comparison condition” depends on the specific comparer:

  • Greater<T> returns true if a is strictly greater than b .
  • Less<T> returns true if a is strictly less than b .
  • EqualTo<T> returns true if both values are equal.

Comparers may define additional rules for handling empty or null optionals, depending on the semantics required by the container or algorithm.
