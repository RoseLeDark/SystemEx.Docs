enum SystemEx.Random.SeedMix : byte

Defines the available mixing strategies used to combine two random seeds. These operations are purely mathematical and intended for non‑cryptographic random number generation. Each mode describes how the corresponding seed values are combined to produce a new mixed seed.

Enumerator
XOR 

Bitwise exclusive OR (XOR) between corresponding seed values. Produces strong bit diffusion and is commonly used in PRNG mixing.

Addition 

Adds corresponding seed values. Useful for linear seed combination.

Subtraction 

Subtracts the other seed value from the current one.

Multiplication 

Multiplies corresponding seed values. Produces strong variation and is used in several classical random generators.

And 

Bitwise AND between corresponding seed values. Can be used to mask or restrict certain bits.

Or 

Bitwise OR between corresponding seed values. Aggregates bits from both seeds.

ShiftLeft 

Shifts the current seed value left by a shift amount derived from the other seed and the provided mix parameter.

ShiftRight 

Shifts the current seed value right by a shift amount derived from the other seed and the provided mix parameter.

RotateLeft 

Rotates the current seed value left by a rotation amount derived from the other seed and the provided mix parameter.

RotateRight 

Rotates the current seed value right by a rotation amount derived from the other seed and the provided mix parameter.

Not 

Bitwise negation (NOT) of the current seed value.

Minimal 

Takes the minimum of the two corresponding seed values.

Maximal 

Takes the maximum of the two corresponding seed values.

Average 

Computes the average of the two corresponding seed values.

New 

Replaces the current seed entirely with the other seed.

User 

Uses a user‑defined mixing function provided via Func<ISeed, ISeed, ISeed> OnUserMix. This allows custom mixing logic beyond the predefined strategies.
