Detailed Description

A Read-Copy-Update (RCU) wrapper around a Stream that provides lock-free read operations and exclusive write operations. Reader activity is tracked through an Epoch, while writers are synchronized using an ILock. This ensures deterministic behavior in concurrent read/write scenarios without requiring external synchronization.
