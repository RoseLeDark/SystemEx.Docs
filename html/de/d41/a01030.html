Detailed Description

Provides a standard comparison implementation for values wrapped in Optional<T> where T implements IComparable<T>.

The comparison delegates to Optional<T>.CompareTo(Optional<T>), which defines ordering semantics for present and non‑present values.

TThe value type being compared. Must implement IComparable<T>.

Parameters

Returns
A CompareResult describing the ordering:
  • CompareResult.AIsSmallerB if x is null or smaller.
  • CompareResult.AIsLargerB if x is larger or y is null.
  • CompareResult.Equal if both values are equal.
  • CompareResult.Null if both values are null.
