Detailed Description

Represents a lightweight event group based on a fast bit‑storage type. EventGroup<TFastType> allows individual bit positions to be set, cleared, flipped, queried, or waited on. The underlying bit container is provided by TFastType , which must implement IFastType.

This class is thread‑safe and uses LightLock to synchronize access to the bit field.

Template Parameters
TFastTypeA fast bit‑storage type implementing IFastType. The type must provide methods for reading, writing, and flipping individual bit positions.
