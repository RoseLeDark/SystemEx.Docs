Detailed Description

Represents a pinned unmanaged memory block used by SystemEx backends.

This structure is essential for passing raw pointers to native code. When a byte array is pinned using GCHandle, the garbage collector is prevented from relocating it. This guarantees that the unmanaged pointer (Point) remains stable for the entire duration of the native kernel execution.

SystemEx uses UnmanagedObject as the bridge between managed buffers (byte[]) and native compute kernels.
It provides:

  • A stable unmanaged pointer
  • The raw byte data
  • The size of the memory block
  • Automatic cleanup via Dispose

This type is lightweight and disposable. Backends create it when a buffer is shared with native code and release it once the kernel finishes execution.
