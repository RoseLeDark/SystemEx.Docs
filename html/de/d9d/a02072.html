Detailed Description

A thin wrapper around operating‑system synchronization primitives (Mutex and EventWaitHandle).

This class provides a blocking, kernel‑managed mutex lock.
It is fundamentally different from LightMutex<T>, which is a non‑blocking, atomic spinlock‑based mutex implemented entirely in user space.

Important: This OS‑level mutex performs kernel transitions, may block threads, and does not use atomic operations. It should not be mixed or substituted with LightMutex<T> or LightCountingSpinlock<T> unless the synchronization model explicitly requires blocking behavior.
