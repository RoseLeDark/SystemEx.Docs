Detailed Description

Defines a 128‑bit floating‑point format based on IFloat<TSelf, UInt128>.

Implementations of ICQuad<TSelf> represent quad‑precision floating‑point formats. These formats are suitable for scientific computing, high‑precision simulation, and extended numeric analysis.
