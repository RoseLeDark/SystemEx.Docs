Detailed Description

Represents a layered mathematical canvas system composed of multiple sub‑canvases. Each layer is a deterministic transformation applied on top of the base canvas, forming a purely mathematical composition model rather than a graphical drawing system.

Layers do not store rendered pixels. Instead, each layer contributes transformation rules, blend operations, or color modifications that are applied when the final pixel buffer is requested through GetPixels or when swapped into another canvas via SwapIn.

The system is fully deterministic: the same layer configuration always produces the same composed result.
