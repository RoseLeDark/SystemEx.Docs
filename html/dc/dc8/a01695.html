Detailed Description

Provides low-level IEEE‑754 bit inspection and manipulation for 32‑bit floating-point values. This type follows the naming and structural conventions of the Fast_Type family, but is specialized for floating-point analysis rather than general-purpose bitmask operations.

Exposes:

  • Sign bit (1 bit)
  • Exponent (8 bits)
  • Mantissa (23 bits)

Uses SystemEx byte conversion utilities for endian-safe reinterpretation.
