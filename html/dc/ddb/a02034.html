Detailed Description

Provides a minimal lock‑protected wrapper around a value of type T using a caller‑supplied lock implementation.

LockedObject<T, TL> offers simple, scoped access to a protected value. Read and write operations attempt to acquire the underlying lock and return false if the lock cannot be obtained within the specified timeout.

This type is intentionally lightweight and does not provide RAII‑style access or complex synchronization semantics. It is suitable for small, isolated critical sections where a single value must be protected.

Template Parameters
TThe type of the stored value.
TLThe lock type used to guard access. Must implement ILock.
