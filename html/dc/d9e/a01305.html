Detailed Description

Extends IContainer<T> with linear append semantics.

A linear container supports efficient push‑back operations and may automatically grow its internal storage when IAutoGrowe.AutoGrow is enabled. This interface is typically implemented by dynamic arrays, ring buffers, and other sequential data structures.
