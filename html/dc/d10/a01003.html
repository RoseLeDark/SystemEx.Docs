Detailed Description

Provides a numeric comparison implementation for values wrapped in Optional<T> where T implements INumber<T>.

This comparer supports both strict and non‑strict relational operators, enabling finer‑grained comparison results for numeric types.

CompareResult SystemEx.Algorithms.ValueComparer< T >.Compare ( Optional< T > x,
Optional< T > y )

Compares two numeric values using relational operators provided by INumber<T>. Supports both strict and non‑strict ordering.

Parameters
xThe first numeric value. May be null.
yThe second numeric value. May be null.
Returns
A CompareResult describing the relation:
  • CompareResult.EqualLess if x <= y.
  • CompareResult.EqualGreater if x >= y.
  • CompareResult.Less if x < y.
  • CompareResult.Greater if x > y.
  • CompareResult.Equal if both values are numerically equal.
  • CompareResult.Null if both values are null.
