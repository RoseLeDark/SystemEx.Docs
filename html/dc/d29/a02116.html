Detailed Description

Provides a low-level bit window over a referenced uint value. This type exposes individual bits as a mutable span-like view with support for forward, reverse, and ring-based indexing modes.

Warning: This API is intended for advanced developers only. It operates directly on a referenced integer and mutates its bits without safety guards, bounds normalization, or copy-on-write semantics. Incorrect usage may lead to unexpected side effects, corrupted state, or infinite iteration when using ring mode.

ref struct: The type is stack-only and cannot be boxed, stored on the heap, captured by lambdas, or used in async methods.

Direct bit mutation: All operations modify the underlying integer in-place. Multiple spans referencing the same integer will observe each other's changes.

Windowed view: The span exposes only the bits between Start and End. Access outside this range throws exceptions.

Indexing modes:

  • System: forward indexing (Start → End).
  • Reverse: backward indexing (End-1 → Start).
  • Ring: cyclic indexing; enumeration never terminates.

Warning: This constructor creates a span-like structure that operates directly on a referenced integer. All bit reads and writes mutate the original value in-place. Multiple spans referencing the same integer will observe and affect each other's changes.

Because BitUIntSpan is a ref struct, it is restricted to stack-only usage. It cannot be boxed, stored on the heap, used in async methods, or captured by closures.

Incorrect window boundaries or misuse of FlexSpanMode.Ring may lead to out-of-range exceptions or infinite iteration. This API is intended for advanced developers who fully understand bit-level operations.

Parameters

Returns
true if the bit is set; otherwise false.
Exceptions
ArgumentOutOfRangeExceptionThrown when index exceeds the view length.

The returned bit depends on the active FlexSpanMode:

  • System: direct forward mapping.
  • Reverse: mirrored mapping from the end.
  • Ring: index wraps modulo the view length.

Warning: This method reads directly from the referenced integer. Concurrent modifications will be reflected immediately.
