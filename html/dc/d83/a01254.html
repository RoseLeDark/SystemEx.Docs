Detailed Description

Provides a multi‑branch delegate dispatcher driven by a switch‑condition.

SwitchDelegate<TS, T> extends the concept of IFDelegate<T> by supporting an arbitrary number of conditional branches. Each branch is identified by a case key of type TS and holds its own delegate chain.

When Invoke is called, the condition function selects the active case, and the corresponding delegate chain is executed. If no delegate is registered for the selected case, nothing is invoked.

This type is useful for state‑based dispatching, multi‑mode processing, or any scenario where behavior depends on a discrete selector rather than a boolean condition.
