Detailed Description

Provides an RAII-style scoped lock for any ILock implementation and exposes a snapshot of a protected value. The lock is acquired in the constructor and automatically released when the instance is disposed.

Creates a new UniqueLock<T, TL> and attempts to acquire the specified lock. If the lock cannot be acquired within the given timeout, an UnauthorizedAccessException is thrown. The provided value is captured by reference and stored as a snapshot.
