Detailed Description

Represents a generic FP8 MX‑block consisting of 32 FP8 elements of type T sharing a common block exponent.

MX‑blocks are used to accelerate FP8 vector operations by applying a shared exponent scaling across all 32 elements. This allows efficient SIMD‑style arithmetic while preserving FP8 semantics.

The type parameter T must implement IFP8<T> and IP8MXEnable, providing FP8 format metadata such as HiddenBit, MantissaMask, ExponentBias, MaxExponent, and ShiftRaster.
