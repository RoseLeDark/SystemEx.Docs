Detailed Description

A Simple priority queue implemented .
Elements are stored as Pair<T, TU> where T is the value and TU is the priority.
Supports enqueue, dequeue, peek, priority updates, cloning, and median‑based selection.

Template Parameters
TElementThe stored value type.
TPriorityThe priority type, must implement INumber<TU> to allow arithmetic and comparison operations.
