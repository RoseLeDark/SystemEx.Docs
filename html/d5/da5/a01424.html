Detailed Description

A sparse, linear container that stores elements as Tuple<T> objects, each consisting of a single key of type T and an arbitrary number of additional values.

Unlike Map<T, TU>, which stores fixed two‑value pairs, TupleMap<T> supports variable‑length, heterogeneous value sequences per key. This makes it suitable for scenarios where each key represents a record, row, or structured entry with multiple fields.

The container behaves like a sparse vector: inactive slots remain allocated but are ignored during traversal, lookup, and enumeration. This design enables efficient slicing, copying, and low‑level operations without compacting or reallocating the underlying storage.

Automatic growth is controlled through GrowSize and AutoGrow. When enabled, the internal buffer expands automatically to accommodate additional tuples.
