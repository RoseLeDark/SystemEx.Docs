Detailed Description

Represents a 32‑element MX‑block of FloatUE4M3 values using Float8UMX<T> as the underlying generic FP8 MX engine.

This type provides a convenient strongly‑typed wrapper for FloatUE4M3 MX blocks, allowing direct construction without specifying the generic parameter.

The shared exponent controls the block‑wide scaling factor used during MX arithmetic (Add/Sub/Mul/Div). All FP8 operations follow the unsigned E5M2 FP8 rules implemented in FloatUE4M3.
