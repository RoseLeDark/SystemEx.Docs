Detailed Description

Defines a minimal lock‑protected value container interface. Implementations provide controlled read and write access to a value of type T using a caller‑supplied synchronization mechanism.

The interface abstracts simple lock‑based protection for a single value. Read and write operations may block depending on the lock implementation and the specified timeout.

Template Parameters
TThe type of the protected value.
