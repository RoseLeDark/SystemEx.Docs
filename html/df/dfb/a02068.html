Detailed Description

Represents a minimal Read-Copy-Update (RCU) container that provides lock-free read access and exclusive write access to a protected value. Reader activity is tracked through an Epoch instance, while writers are synchronized using an ILock.

Template Parameters
TThe type of the value being protected by the RCU object.
