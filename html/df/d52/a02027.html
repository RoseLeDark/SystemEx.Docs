Detailed Description

Represents a basic geometric projection descriptor containing field‑of‑view, aspect ratio, and near/far clipping planes.

Projection stores the fundamental scalar parameters required to construct a perspective projection transform. Although this type does not generate matrices itself, it provides the canonical values used by rendering pipelines, shader systems, or future matrix utilities.

The structure is intentionally lightweight and immutable in layout. It is suitable for passing projection parameters between CPU subsystems, GPU kernels, or mathematical utilities without imposing a specific matrix representation.
