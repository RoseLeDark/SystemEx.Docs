enum SystemEx.AI.BackendCapabilities : int

Defines capability flags for AI backends.

Naming follows the AI_BACKEND_CAPS_XXX convention. These flags describe what features a backend supports, such as text generation, audio processing, vision models, tool execution, platform integration, and hardware acceleration.

Describes capabilities supported by an AI backend.

This enum is intentionally broad and future-proof. It covers:

  • Local and remote execution
  • GPU/CPU/WASM/native runtimes
  • Text, chat, audio, vision, video, multimodal
  • Tools, agents, function calling
  • Embeddings, vector search, batch processing
  • Platform-specific capabilities (Windows, Web, Mobile)
  • Custom developer-defined capabilities

Naming follows AI_BACKEND_CAPS_XXX.

enum SystemEx.AI.MetaFormat : int

Defines the data format returned by a backend during model execution.

This enum follows the AI_FORMAT_XXX naming convention and provides stable integer identifiers for all supported formats.

Enumerator
AI_FORMAT_JSON 

JSON object or array. The default format for most Web APIs.

AI_FORMAT_TEXT 

Plain text or raw string output.

AI_FORMAT_XML 

XML document format.

AI_FORMAT_YAML 

YAML document format, commonly used for configuration files.

AI_FORMAT_INI 

INI-style key-value configuration format.

AI_FORMAT_BINARY 

Raw binary data without a predefined structure.

AI_FORMAT_PROTOBUF 

Google Protocol Buffers (Protobuf) binary format.

AI_FORMAT_MSGPACK 

MessagePack binary JSON format.

AI_FORMAT_HTML 

HTML document format.

AI_FORMAT_MARKDOWN 

Markdown text format.

AI_FORMAT_TOKENS 

Token arrays or token streams produced by language models.

AI_FORMAT_EMBEDDING 

Vector embeddings (float arrays) produced by embedding models.

AI_FORMAT_IMAGE 

Image data (PNG, JPG, BMP, WebP, etc.).

AI_FORMAT_AUDIO

AI_FORMAT_VIDEO

AI_FORMAT_CUSTOM 

Any custom developer-defined format not covered by the predefined types.
