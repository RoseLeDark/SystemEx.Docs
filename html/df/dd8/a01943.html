Detailed Description

A lightweight non‑blocking mutex built on top of LightCountingSpinlock<T>. This mutex provides binary spinlock semantics (capacity 1) combined with strict owner‑tracking to ensure that only the thread which successfully acquired the lock may access the protected value or release the lock.
