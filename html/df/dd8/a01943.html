Detailed Description

Represents an FP8 value encoded in the industry‑standard E4M3 format.

This format uses:

• 1 sign bit

• 5 exponent bits (bias = 7)

• 2 mantissa bits

The hidden bit is always 1 for normalized numbers. Subnormal numbers use an exponent of zero and do not include the hidden bit.

This implementation is fully self‑contained and performs all arithmetic, comparisons, and classifications purely on FP8 bit‑patterns without converting to host floating‑point types.
