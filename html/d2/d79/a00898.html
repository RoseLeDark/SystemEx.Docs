Detailed Description

Defines a pluggable search strategy for use with the Search object.

Defines a minimal comparison strategy for two values of type T .

A search provider encapsulates the lookup logic and can implement any strategy: linear scan, binary search, segmented search, pattern matching, or domain‑specific evaluation.

The provider receives the container by reference to allow efficient access without copying. It never modifies the container.

Template Parameters
TContainerThe container type implementing IVector<T>.
TThe element type stored in the container.

Implementations provide a single boolean comparison operation, allowing containers, sorting policies, and search utilities to determine ordering or equivalence without requiring full IComparer<T> or IComparable<T> semantics.

Template Parameters
TThe type of elements being compared.
