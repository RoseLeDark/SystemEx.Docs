Detailed Description

A modern, policy‑driven dynamic Vector container that provides fast indexed access, optional auto‑growth, insertion, removal, traversal, and multiple zero‑overhead reinterpretation views.

Beyond basic dynamic array functionality, Vector<T> supports several high‑level transformations such as:

  • AsFlexSpan – a multi‑mode span view supporting forward, reverse, and ring ( circular) traversal.
  • AsSet / AsMultiSet – sorted views with configurable comparison and sorting policies.
  • AsUnorderedSet / AsUnorderedMultiSet – unordered unique or multi‑value views without sorting overhead.
  • AsSearch – a binary‑search optimized lookup view.
  • AsFind – a linear search view for unsorted data.

These views allow the same underlying Vector to be interpreted as a span, a sorted set, a multiset, an unordered set, or a search helper — without copying or allocating additional memory.

Beginners:
Think of Vector<T> as a dynamic array that can instantly transform into different “shapes” such as a set, a multiset, or a span, depending on what you need.

Professionals:
Vector<T> follows a modern C++‑style multi‑view design. Ordering is defined by ISimpleCompare<T> strategies, sorting is controlled by SortAction<TCompare, TContainer> policies, and all reinterpretations are zero‑overhead wrappers.
This enables policy‑based sorting, strategy‑based comparison, and flexible container semantics without hidden allocations or implicit behavior.
