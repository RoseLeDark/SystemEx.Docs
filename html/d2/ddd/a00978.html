Detailed Description

Converts an IModelTool<T> definition into a backend‑specific function object that can be exposed to an AI model.

A factory implementing IAIFunctionFactory<T, TAITOOL> is used by model backends to translate internal tool definitions into the concrete function format required by the underlying AI runtime.
This enables consistent tool‑exposure across different model backends, runtimes, and execution environments.

Template Parameters
TThe prompt type used by the model backend.
TAITOOLThe backend‑specific function type produced by the factory.
