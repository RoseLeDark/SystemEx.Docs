Detailed Description

Extends IFastType with typed access to the underlying storage value. Implementations define how the raw value is represented (e.g., uint, ulong, ushort, double, long), enabling bit‑level inspection and mutation of arbitrary numeric formats.

This interface is type‑agnostic and supports both integer and floating‑point representations. For floating‑point types, the bit operations apply to the raw IEEE‑754 encoding (or custom formats such as Half16).

Additional operations include:

  • One’s complement (CmpOne) — invert all bits.
  • Two’s complement (CmpTwo) — invert all bits and add one.
  • Masking (Mask) — apply a bitmask using AND.
  • Mask creation (CreateMask) — generate a contiguous bitmask of arbitrary length.
  • Combination (Combine) — merge two bit patterns using OR.

Implementations must guarantee that all operations modify or inspect the underlying value deterministically and without hidden conversions.
