Detailed Description

Represents a rational number using a signed 64‑bit numerator and denominator.

A Ratio stores an exact fractional value without automatic reduction. This allows the representation of structural fractions such as gear ratios (e.g., 20/60 is preserved and not simplified to 1/3).

The type provides full rational arithmetic, comparison operators, normalization, conversion to floating‑point types, and serialization support.
Negative denominators are normalized internally so that the denominator is always positive.

The struct is sequentially laid out for deterministic memory representation and supports hashing via the HashAlgorithmAttribute.
