Detailed Description

A lightweight and minimal condition variable designed for simple thread synchronization scenarios. Unlike the heavy and business‑oriented primitives in .NET, LightConditionVariable provides a straightforward FIFO wait‑list and wake‑up mechanism suitable for most everyday use cases.

Threads can register themselves using Add(LightThread) and will be resumed explicitly through Signal or Broadcast. No complex monitor logic or advanced runtime scheduling is involved.
