Detailed Description

Provides an RAII-style scoped lock for any ILock implementation and exposes a snapshot of a protected value. The lock is acquired in the constructor and automatically released when the instance is disposed.

SystemEx.Threading.ScopedLock< T, TLOCK >.ScopedLock ( ref TLOCK l,
ref T value,
int timeout = -1 )

Creates a new ScopedLock<T, TL> and attempts to acquire the specified lock. If the lock cannot be acquired within the given timeout, an UnauthorizedAccessException is thrown. The provided value is captured by reference and stored as a snapshot.

Parameters
lThe lock instance to acquire.
valueA reference to the protected value. The value is copied into the Value property once the lock is acquired.
timeoutThe timeout in milliseconds. A value of -1 indicates an infinite wait.
Exceptions
UnauthorizedAccessExceptionThrown when the lock cannot be acquired within the specified timeout.
