Detailed Description

Represents the payload sent to a remote Web‑API based AI backend.

This struct is serialized into JSON and transmitted via HTTP POST. It contains:

  • The target URL
  • The system prompt
  • The raw user prompt
  • Context information
  • Additional model parameters

The generic type T represents the raw prompt type used by the model (e.g., string, structured object).
