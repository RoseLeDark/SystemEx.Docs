Detailed Description

Provides binary serialization and deserialization capabilities for a type. Implementations define how an instance is encoded into a byte sequence and how it is reconstructed from raw binary data.

The interface supports endian‑aware serialization and allows writing the encoded representation into an existing buffer at a specified offset.
