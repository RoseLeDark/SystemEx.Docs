Detailed Description

Represents a chained view over multiple LinkedNodeRange<T> segments, similar to std::views::concat in C++.
A LinkedNodeChain<T> allows iteration across several disjoint ranges of a linked Node<T> structure as if they formed one continuous sequence.

Template Parameters
TThe value type stored in the underlying nodes.

var chain = new LinkedNodeChain<int>() .Add(node.First(), node.At(5)) .Add(node.At(10), node.At(20)) .Add(node.At(30), node.End());

foreach (var x in chain) Console.WriteLine(x);
