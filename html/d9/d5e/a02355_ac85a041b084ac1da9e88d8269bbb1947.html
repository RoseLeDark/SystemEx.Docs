SystemEx.Utils.BitIntSpan.BitIntSpan ( ref int value,
short startPos,
short endPos,
FlexSpanMode mode )

Initializes a new BitIntSpan that exposes a bit-level view over the referenced value .

Parameters
valueA reference to the underlying int whose bits will be read and modified directly. No copy is made.
startPosThe starting bit position of the view (inclusive). Must be within the valid bit range of the underlying integer.
endPosThe ending bit position of the view (exclusive). Must be greater than startPos and within the integer's bit width.
modeThe indexing mode used to interpret bit positions: FlexSpanMode.System, FlexSpanMode.Reverse, or FlexSpanMode.Ring.

Warning: This constructor creates a span-like structure that operates directly on a referenced integer. All bit reads and writes mutate the original value in-place. Multiple spans referencing the same integer will observe and affect each other's changes.

Because BitIntSpan is a ref struct, it is restricted to stack-only usage. It cannot be boxed, stored on the heap, used in async methods, or captured by closures.

Incorrect window boundaries or misuse of FlexSpanMode.Ring may lead to out-of-range exceptions or infinite iteration. This API is intended for advanced developers who fully understand bit-level operations.
