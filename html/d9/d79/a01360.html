Detailed Description

Provides a Read‑Copy‑Update (RCU) wrapper around a Cache instance. Readers operate lock‑free using epoch tracking, while writers acquire an exclusive lock to ensure consistent updates. This enables deterministic, high‑performance concurrent access to a byte‑addressable memory buffer.
