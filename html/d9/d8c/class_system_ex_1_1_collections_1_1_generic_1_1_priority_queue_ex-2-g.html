Detailed Description

A priority queue implemented on top of SortedMap<T, TU>.
Elements are stored as Pair<T, TU> where T is the value and TU is the priority.
Supports enqueue, dequeue, peek, priority updates, cloning, and median‑based selection.

Template Parameters
TThe stored value type.
TUThe priority type, must implement INumber<TU> to allow arithmetic and comparison operations.
Type Constraints
T :notnull 
TU :INumber<TU>
