Detailed Description

Represents an arbitrary‑precision decimal number stored in scientific notation using a BigInteger mantissa and a base‑10 exponent.

Provides amerikanische (US‑Customary) engineering units directly within BigDecimal. These units are widely used in US technical industries, automotive systems, HVAC, construction, and aerospace.

A BigDecimal models values of the form:

value = mantissa × 10^exponent

The mantissa is stored as an unbounded BigInteger, while the exponent is a signed 32‑bit integer. This representation allows exact modeling of extremely small or extremely large numbers without rounding artifacts or loss of precision.

Unlike floating‑point types (float, double), BigDecimal does not normalize its mantissa automatically. The caller may choose any mantissa/exponent combination that represents the desired value. This makes the type suitable for scientific, financial, and mathematical applications where deterministic precision and explicit exponent control are required.

All values are represented exakt as BigDecimal without floating‑ point rounding, making them suitable for precise technical calculations.
