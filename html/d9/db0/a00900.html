◆ ModelName

string SystemEx.AI.IModelBackend< T, TAI >.ModelName
getset

Gets or sets the identifier of the AI model that should be used by the backend.

This value determines which model the Windows AI Runtime will load when executing a request. It can be changed at any time during runtime, allowing dynamic switching between different AI models (e.g., "phi-3-mini", "phi-3-medium", "gpt-4o", etc.).

The ModelName is independent from the agent name used in the Model<T> constructor. While the agent name describes the logical assistant (e.g., "DevAssistant"), the ModelName specifies the actual AI model used for inference.

Returns
A string representing the model identifier passed to the Windows AI Runtime.
