Detailed Description

RAM‑based backend for shared device buffers.

RamSharedBackend is the simplest backend in SystemEx. It stores buffer data directly in managed RAM and exposes it to native kernels by pinning the underlying byte[] and providing an unmanaged pointer via UnmanagedObject.

This backend is primarily used for:

  • Testing native kernels without GPU or hardware devices
  • Debugging compute logic in a safe environment
  • Providing a fallback backend for platforms without specialized hardware

The backend implements the IDeviceSharedBackend interface, allowing SystemEx to treat RAM buffers exactly like hardware buffers. This makes native kernel execution backend‑agnostic:
kernels do not care whether the memory comes from RAM, GPU, or another device.
