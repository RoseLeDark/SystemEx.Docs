Detailed Description

Represents a concrete implementation of IModelPromp<T> used to encapsulate model input, contextual metadata, session information, execution parameters, and optional tags.

ModelPromp<T> is the standard prompt container used by all IModelBackend implementations. It provides a mutable structure for building and enriching prompts before they are passed into the model pipeline, while also supporting functional-style cloning through the With* methods.
