Detailed Description

Represents a model‑executable tool that can be exposed to AI backends through an IAIFunctionFactory.

An IModelTool<T> defines a named operation with a description, a parameter schema, and an asynchronous execution method.
Model backends may convert these tools into runtime‑callable functions when supported, enabling structured tool‑use inside model pipelines.

Template Parameters
TThe prompt type used by the model backend when invoking the tool.
