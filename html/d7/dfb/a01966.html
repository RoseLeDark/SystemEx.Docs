Detailed Description

Represents a reusable multi‑phase synchronization barrier. Threads call Arrive or ArriveAndWait to signal arrival at the current phase. When the number of arrivals reaches m_max, the barrier opens, executes the completion callback, resets its counters, and begins the next phase.

Template Parameters
TThe lock type used to block threads during phase synchronization. Must implement ILock.
