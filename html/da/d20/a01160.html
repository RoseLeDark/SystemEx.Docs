bool SystemEx.Triple.operator false ( Triple opt)

Defines the logical false state for control‑flow usage. This operator does not implement three‑valued logic. It exists solely so that Triple can be used in C# conditional statements such as if, while, and logical operators.

A Triple evaluates to false when its underlying value is triple.False or triple.Nin.
