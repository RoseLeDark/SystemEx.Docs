Detailed Description

Provides a fluent builder for constructing complex Result objects across multiple processing steps, compiler stages, or mathematical operations.

ResultBuilder allows values, diagnostics, assertions, and exceptions to be accumulated progressively. It is designed for scenarios where the final output may contain multiple heterogeneous items or where the success state is determined by several independent operations.

The builder never throws directly; instead, exceptions are captured inside the underlying Result instance. The caller may inspect or re-throw them using Result.Throw.
