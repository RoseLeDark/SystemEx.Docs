enum SystemEx.AI.ModelMeta : int

Defines strongly typed metadata keys for model execution.

Naming follows the AI_META_XXX convention, Values are grouped logically and designed to remain stable for long-term API usage.

These metadata keys describe backend information, model details, request/response properties, execution metrics, tool usage, and error diagnostics.

Enumerator

Name of the backend used to execute the model.

Version string of the backend implementation.

Type of backend (e.g., Local, Remote, WebAPI, WindowsAI).

AI_META_BACKEND_LATENCY 

Measured backend latency in milliseconds.

The Platform where run the backend.
