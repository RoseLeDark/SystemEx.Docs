Detailed Description

Provides a scoped lock mechanism for an existing ILock instance. Upon construction, the lock is acquired using the specified timeout. When the scope ends, Dispose releases the lock.

ScopedLock<TLOCK> offers RAII‑style mutual exclusion similar to C++'s std::scoped_lock, ensuring deterministic lock acquisition and release.
