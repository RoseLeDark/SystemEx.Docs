Detailed Description

Represents a composite seed that can be dynamically mixed with other seeds using a variety of mathematical operations. SeedMixed acts as a wrapper around an existing ISeed instance and provides thread‑safe mixing functionality suitable for all random engines in SystemEx.

Mixes the current seed with another seed using the specified mixing strategy.
